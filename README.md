# TasteBite Restaurant Website

A modern responsive restaurant website built using HTML, CSS and JavaScript.

## Features

- Responsive design
- Restaurant menu
- Food gallery
- Customer reviews
- Table booking form
- WhatsApp booking
- Google Maps integration
- Mobile navigation
- Smooth animations
- SEO metadata
- Favicon

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Structure

tastebite-restaurant/
├── index.html
├── style.css
├── script.js
└── images/

## Project Purpose

TasteBite is a restaurant website demo created as a portfolio project.
